# Proyecto Casino

**Nombre:** Gorka Jesús Quesada Vega  
**Ciclo:** 2 DAM T  

## Descripción

Este proyecto es una simulación de casino programada en Java donde diferentes jugadores realizan apuestas automáticamente usando distintas estrategias mientras una ruleta genera resultados de forma independiente en su propio hilo. La finalidad del proyecto es practicar la programación concurrente con hilos y la sincronización de recursos compartidos, representando de manera realista cómo funciona un casino con múltiples jugadores y una banca centralizada.
